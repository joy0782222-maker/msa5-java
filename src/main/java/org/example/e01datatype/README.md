# e01. 데이터 타입

자바는 **정적 타입 언어**다. 변수를 선언할 때 담을 데이터 타입을 반드시 지정해야 하고, 다른 타입의 값을 넣으면 실행 전에 컴파일 에러가 발생한다.

```java
boolean bool = true;
// bool = 1;  // 컴파일 에러: boolean 변수에 int를 넣을 수 없음
```

| | JavaScript | Java |
| --- | --- | --- |
| 변수 선언 | `let a = 1` | `int a = 1` |
| 다른 타입 대입 | 가능 | 불가 (컴파일 에러) |
| 에러 발견 시점 | 실행 시 | 코드 작성 시 |

---

## 1. 기본형과 참조형

| | 기본형 (Primitive) | 참조형 (Reference) |
| --- | --- | --- |
| 종류 | 8개 | 기본형을 제외한 전부 (String, 배열, 클래스 등) |
| 저장 방식 | 값 자체를 스택에 저장 | 실제 값은 힙에 저장하고, 변수에는 주소를 저장 |
| `null` | 저장 불가 | 저장 가능 |

- 객체는 크기가 크기 때문에 변수마다 복사하지 않고, 힙에 하나만 생성한 뒤 주소로 공유한다.
- `null`은 "참조하는 객체가 없음"을 나타내는 값이다. 기본형은 항상 값을 가져야 하므로 `null`을 저장할 수 없다.
- 클래스를 하나 만들면 그 클래스 이름이 곧 하나의 타입이 된다. 따라서 참조형의 종류는 제한이 없다.

---

## 2. 기본형 8가지

| 분류 | 타입 | 범위 / 특징 | 접미사 |
| --- | --- | --- | --- |
| 논리형 | `boolean` | `true` / `false` | |
| 정수형 | `byte` | -128 ~ 127 | |
| | `short` | -32,768 ~ 32,767 | |
| | **`int`** | 약 ±21억 (**정수 기본형**) | |
| | `long` | 약 ±922경 | `L` |
| 실수형 | `float` | | `F` |
| | **`double`** | **실수 기본형** | |
| 문자형 | `char` | 한 글자 (유니코드) | |

```java
byte bt = -13;
short sh = 32767;
int integer = 2147483647;
long longer = 214745373553L; // long은 마지막에 L
double db = 3.141592;
float ft = 3.141597F;        // float은 마지막에 F
char ch1 = 'g';
```

## 3. 변수와 상수

```java
int age;        // 선언: 저장 공간 생성
age = 1;        // 초기화: 처음 값을 대입

final String USER_NAME = "oo";   // 상수
// USER_NAME = "LL";             // 컴파일 에러: final 변수는 재할당 불가

int num = 1_757_450_745;         // 언더스코어 표기법 (세 자리마다 _)
```

| 대상 | 표기법 | 예시 |
| --- | --- | --- |
| 변수 | camelCase | `userName` |
| 상수 | UPPER_SNAKE_CASE | `USER_NAME` |
| 클래스 | PascalCase | `E01DataType` |
| 패키지 | 소문자 | `e01datatype` |

## 4. 스와핑 (두 변수의 값 교환)

```java
int swap1 = 1;
int swap2 = 2;
int swap3;

swap3 = swap1;   // 1. 임시 변수에 swap1 값을 보관
swap1 = swap2;   // 2. swap1에 swap2 값을 대입
swap2 = swap3;   // 3. 보관해 둔 값을 swap2에 대입
```

바로 대입하면 기존 값이 덮어써져 사라지기 때문에 임시 변수가 필요하다. 정렬 알고리즘에서 두 값의 위치를 바꿀 때 이 방식을 사용한다.

## 헷갈리기 쉬운 포인트

### `long`과 `float`에 접미사를 붙이는 이유
정수 리터럴은 기본적으로 `int`, 실수 리터럴은 기본적으로 `double`로 인식된다.
- `L`을 붙이지 않으면 `int` 범위를 넘는 숫자는 컴파일 에러가 발생한다.
- `F`를 붙이지 않으면 `double`로 인식되어 `float` 변수에 대입할 수 없다.
- 소문자 `l`은 숫자 `1`과 혼동되므로 대문자 `L`을 사용한다.

### `char`와 `String`
| | `char` | `String` |
| --- | --- | --- |
| 분류 | 기본형 | 참조형 |
| 길이 | 한 글자 | 여러 글자 |
| 따옴표 | 작은따옴표 `'a'` | 큰따옴표 `"a"` |

`String`은 문자(`char`)의 배열로 구현되어 있고, 배열은 참조형이기 때문에 `String`도 참조형이다.

### `char`에 숫자를 넣으면?
`char`는 내부적으로 유니코드 번호로 저장되기 때문에 `char c = 97;`은 에러 없이 `'a'`가 된다. 의도가 명확하지 않으므로 이렇게 사용하지 않는다.

### 오버플로우와 언더플로우
타입이 저장할 수 있는 최댓값보다 큰 값을 넣으면 오버플로우, 최솟값보다 작은 값을 넣으면 언더플로우다.

### 실수 오차
`0.1 + 0.2`는 정확히 `0.3`이 되지 않는다. 실수를 부동소수점 방식으로 저장하기 때문이다. 금액처럼 정확한 계산이 필요하면 `BigDecimal`을 사용한다.

---

## 언제 무엇을 사용하나

| 상황 | 사용 |
| --- | --- |
| 일반적인 정수 | `int` |
| ID처럼 값이 커질 수 있는 정수 | `long` |
| 일반적인 실수 | `double` |
| 금액처럼 정확해야 하는 계산 | `BigDecimal` |
| 한 글자 | `char` |
| 그 외의 문자열 | `String` |
| 변경되면 안 되는 값 | `final` 상수 |

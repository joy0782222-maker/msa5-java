# e02. 연산자

## 1. 산술 연산자

| 연산자 | 의미 | `2 ○ 5` 결과 |
| --- | --- | --- |
| `+` | 더하기 | `7` |
| `-` | 빼기 | `-3` |
| `*` | 곱하기 | `10` |
| `/` | 나누기 (몫) | `0` |
| `%` | 나머지 | `2` |

```java
int num1 = 2;
int num2 = 5;
System.out.println(num1 / num2); // 0
System.out.println(num1 % num2); // 2
```

정수끼리 나누면 결과도 정수다. 소수점 이하는 버려지고 몫만 남는다.

---

## 2. 대입 연산자 / 산술 대입 연산자

```java
int num3 = 1;
num3 = num3 + 3;  // 4
num3 += 3;        // 7 (위와 같은 의미)
```

`+=`, `-=`, `*=`, `/=`, `%=` 모두 같은 방식으로 동작한다.

---

## 3. 증감 연산자

| 표기 | 이름 | 동작 |
| --- | --- | --- |
| `i++` | 후위 증가 | 현재 값을 사용한 뒤 1 증가 |
| `++i` | 전위 증가 | 1 증가한 뒤 값을 사용 |

```java
int num5 = 0;
System.out.println(num5++); // 0 출력 후 num5 = 1
System.out.println(++num5); // num5 = 2 로 증가 후 2 출력
```

---

## 4. 비교 연산자

| 연산자 | 의미 |
| --- | --- |
| `>` `<` | 크다 / 작다 |
| `>=` `<=` | 크거나 같다 / 작거나 같다 |
| `==` | 같다 |
| `!=` | 같지 않다 |

결과는 항상 `boolean`(`true` / `false`)이다.

---

## 5. 논리 연산자

| 연산자 | 의미 | 결과가 `true`인 경우 |
| --- | --- | --- |
| `&&` | AND | 양쪽 모두 `true` |
| `\|\|` | OR | 한쪽이라도 `true` |
| `!` | NOT | 결과를 반대로 |

```java
int num10 = 0;
int num11 = 2;
System.out.println(num10 > 0 && num11 <= 11); // false
System.out.println(num10 > 0 || num11 <= 11); // true
System.out.println(!(num10 > 0));             // true
```

## 6. 삼항 연산자

```java
// 조건 ? 참일 때 값 : 거짓일 때 값
String result = num1 > num2 ? "num1b" : "num1s";
```

결과가 두 가지뿐일 때 `if-else`를 한 줄로 줄일 수 있다.

## 헷갈리기 쉬운 포인트

### 문자열 비교: `==` vs `equals()`

```java
String str1 = "str1";
String str2 = "str1";
String str3 = new String("str1");

str1 == str3        // false
str1.equals(str3)   // true
```

| | `==` | `equals()` |
| --- | --- | --- |
| 비교 대상 | 변수에 저장된 값 (참조형이면 **주소**) | 주소가 가리키는 **실제 값** |
| 문자열 비교에 사용 | X | O |

- `"str1"`처럼 리터럴로 만든 문자열은 **String Pool**에서 같은 객체를 공유한다. 그래서 `str1 == str2`는 우연히 `true`가 나온다.
- `new String()`으로 만들면 새로운 객체가 생성되어 주소가 달라진다. 그래서 `==`는 `false`다.
- 어떤 방식으로 만들었는지와 관계없이 **문자열 비교는 항상 `equals()`를 사용한다.**

### 전위 / 후위 증감 연산자
다른 연산 중간에 증감 연산자를 넣으면 실행 순서가 헷갈리고 버그가 생기기 쉽다. 실무에서는 증감 연산을 별도의 한 줄로 분리해서 사용한다.

```java
// 지양
System.out.println(count++);

// 권장
count++;
System.out.println(count);
```

### 실수 비교
`0.1F + 0.2F == 0.3F`처럼 연산 결과를 비교하면 부동소수점 오차 때문에 의도와 다른 결과가 나올 수 있다. 정확한 계산이 필요하면 `BigDecimal`을 사용하거나, 정수로 변환해 계산한다.

## 언제 무엇을 사용하나

| 상황 | 사용 |
| --- | --- |
| 몫 | `/` |
| 나머지, 짝수/홀수 판별 | `%` |
| 결과가 두 가지뿐인 짧은 분기 | 삼항 연산자 |
| 결과가 세 가지 이상인 분기 | `if-else if` |
| 문자열이 같은지 비교 | `equals()` |

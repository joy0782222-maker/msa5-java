# e04. 반복문 (for / while)

## 1. for

```java
// for (초기값; 조건; 증감) { 반복할 코드 }
for (int i = 0; i < 5; i++) {
    System.out.println(i);   // 0 1 2 3 4
}
```

실행 순서:
1. 초기값 실행 (`int i = 0`) — 처음 한 번만 실행
2. 조건 검사 (`i < 5`) — `false`면 반복 종료
3. 본문 실행
4. 증감 실행 (`i++`)
5. 2번으로 돌아감

---

## 2. 중첩 for문

```java
for (int i = 0; i < 2; i++) {
    for (int z = 0; z < 5; z++) {
        System.out.printf("i값: %d, z값: %d%n", i, z);
    }
}
```

바깥 반복문이 한 번 돌 때마다 안쪽 반복문은 처음부터 끝까지 모두 실행된다. 위 코드의 본문은 `2 × 5 = 10`번 실행된다.

### 실습: 구구단 2~9단

```java
for (int i = 2; i <= 9; i++) {
    System.out.printf("** %d단 **%n", i);
    for (int z = 1; z <= 9; z++) {
        System.out.printf("%d x %d = %d%n", i, z, (i * z));
    }
    System.out.println();
}
```

- 바깥 반복문 `i`: 단 (2~9)
- 안쪽 반복문 `z`: 곱하는 수 (1~9)

---

## 3. while

```java
int count = 0;
while (count < 5) {
    System.out.println(count);
    count++;
}
```

조건이 `true`인 동안 계속 반복한다. 반복 횟수가 정해져 있지 않고 조건만 있을 때 사용한다.

## 헷갈리기 쉬운 포인트

### 무한 루프는 왜 생길까?
무한 루프는 `break`가 없어서가 아니라 **조건이 계속 `true`로 유지될 때** 생긴다.

```java
// 증감을 빠뜨려 i가 계속 0 → 무한 루프
for (int i = 0; i < 5; ) {
    System.out.println(i);
}
```

`while`은 증감 코드를 본문 안에 직접 작성해야 하므로 빠뜨리기 쉽다. 그래서 `while`은 무한 루프 위험이 더 크다.

### `break`의 의미는 위치에 따라 다르다

| 위치 | 의미 |
| --- | --- |
| `switch` 안 | 다음 `case`로 넘어가지 않고 `switch`를 빠져나감 |
| 반복문 안 | 반복을 즉시 종료하고 반복문을 빠져나감 |

반복문은 `break`가 없어도 조건이 `false`가 되면 정상적으로 종료된다. `break`는 중간에 일찍 빠져나가야 할 때만 사용한다.

### 증감 연산자 사용 위치
`for`문의 증감 부분(`i++`)이나 별도의 한 줄처럼 **단독으로** 사용하면 `i++`와 `++i`의 결과가 같다. 다른 연산 중간에 넣을 때만 차이가 생기므로, 증감 연산은 단독으로 사용하는 것을 권장한다.

## for vs while

| | for | while |
| --- | --- | --- |
| 사용 상황 | 반복 횟수가 정해져 있을 때 | 조건만 있고 횟수를 모를 때 |
| 초기값·증감 위치 | `for` 괄호 안에 함께 작성 | 반복문 밖과 본문 안에 따로 작성 |
| 무한 루프 위험 | 상대적으로 낮음 | 상대적으로 높음 |

## 언제 무엇을 사용하나

| 상황 | 사용 |
| --- | --- |
| 정해진 횟수만큼 반복 (구구단, 1~100) | `for` |
| 2차원 형태의 반복 (단 × 곱하는 수, 행 × 열) | 중첩 `for` |
| 조건을 만족하는 동안 반복 | `while` |
| 반복 중간에 종료 | `break` |
